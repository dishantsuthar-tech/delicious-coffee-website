# ☕ Delicious Coffee Website

A simple and responsive coffee website built using **HTML and CSS** as part of my web development learning journey.

This project helped me practice and apply the CSS concepts I learned, including Flexbox, layouts, spacing, and responsive design.

## 🌐 Live Demo

**[View Delicious Coffee Website](https://dishantsuthar-tech.github.io/delicious-coffee-website/)**

## 🚀 Features

- Responsive website layout
- Navigation bar with links
- Sidebar navigation section
- Coffee image gallery
- Flexbox-based layout
- Responsive design using media queries
- CSS variables for reusable colors
- Hover effects on navigation links

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📚 Concepts Practiced

- Semantic HTML
- Flexbox (`display`, `flex-basis`, `flex-grow`, `justify-content`, `gap`)
- Margin and padding
- Borders and backgrounds
- CSS variables
- Pseudo-classes (`:hover`, `:last-of-type`)
- Image styling (`aspect-ratio`, `object-fit`)
- Media queries
- Responsive layouts

## 🎯 Purpose

This project was created to strengthen my understanding of HTML and CSS by building a real webpage from scratch and applying the concepts learned during my web development journey.
