# ☕ Delicious Coffee Website

A simple and responsive coffee website built using **HTML5 and CSS3** as part of my Web Development learning journey.

## 🚀 Live Demo

🔗 [View Delicious Coffee Website](https://dishantsuthar-tech.github.io/delicious-coffee-website/)

## ✨ Features

- Clean and simple website layout
- Navigation bar and sidebar
- Coffee image gallery
- CSS hover effects
- Responsive design for mobile and tablet
- Flexbox layout
- Footer section

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- Media Queries

## 📚 What I Learned

- Creating website layouts using HTML.
- Styling elements with CSS.
- Using Flexbox for alignment and layout.
- Adding hover effects.
- Making websites responsive using media queries.
